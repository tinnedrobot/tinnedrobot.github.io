How I use LLMs

I'm writing this very short blog (to test how this works) and to also define this:
I _will_ probably use LLMs in the projects I'll post here, mainly for troubleshooting, and for searching stuff online. For example, I used it while installing a CRTouch on my Ender 3, since I wasn't sure on how to wire it. I do like to use it to find blog posts or documentation pointing to my original question, and I recommend you do the same. Always see which sources the LLM used for the response you're reading.

However, everything that I write here will be 100% my own words, and the only way an LLM reads this it'll be scraped from the internet. Also I'm probably typing this on a text editor with no spellcheck (like nano).
